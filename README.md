# vagmotors

Редизайн главной страницы [vagmotors.by](https://vagmotors.by/): специализированный сервис Volkswagen, Audi, Škoda, SEAT, Porsche и Bentley в Минске.

Статический сайт без сборки, публикуется через GitHub Pages из корня ветки `main`: https://dirol982.github.io/vagmotors/

- `index.html` — главная: запись на СТО, марки, услуги с ценами «от», калькулятор заказа с предчеком, ремонт DSG, гарантия, цех, отзывы, юрлицам, контакты
- `price.html` — прайс по маркам (Volkswagen, Audi, Škoda) с поиском
- `assets/css/style.css` — стили, анимации, адаптив
- `assets/js/main.js` — шапка и меню, статус «открыто/закрыто» по времени Минска, появление блоков, счётчики гарантии, горизонтальная галерея, отзывы, форма записи, калькулятор (добавление и удаление работ, пересчёт по марке, сохранение в браузере, отправка предчека), вкладки и поиск в прайсе
- `assets/img/` — фото цеха и логотип с vagmotors.by, пережатые в WebP
- `assets/fonts/` — Geologica и Golos Text (SIL OFL)

Калькулятор: цены «от» из прайса vagmotors.by/price/ (Volkswagen, Audi, Škoda), данные лежат JSON-блоком внутри `index.html`. На телефоне внизу закреплены «Позвонить» и «Предчек», предчек открывается шторкой.

Заявки работают без сервера: форма и предчек собирают текст и открывают Telegram, Viber или WhatsApp на +375 29 620-04-21 (текст также копируется в буфер). Чтобы заявки приходили автоматически, подключите Telegram-бота или обработчик форм в `main.js`.

Локальный просмотр:

```bash
python3 -m http.server 8000
```

Дизайн-система описана в `DESIGN.md`, факты о продукте — в `PRODUCT.md`.
